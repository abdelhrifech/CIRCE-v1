# Écarts existant vs cible

Convention : `ECART-nnn` (CLAUDE.md §5). Un écart = un changement voulu par une spec entre le comportement legacy (`circe-develop`) et la cible, ou un comportement NOUVEAU visible par rapport au legacy. Les RG citées sont celles de `docs/RECEPTION_REGLES_METIER.md` et `docs/COORDINATION_REGLES_METIER.md` ; la colonne « Source de la cible » reprend les sources des RG (spec `doc §` / `EX-…` / `ECR-…`) et ajoute les questions liées calculées depuis le champ « Questions liées » de ces RG. Aucun écart n'est tranché ici : ce qui n'est pas explicitement voulu par une spec est renvoyé à une question (`docs/QUESTIONS_OUVERTES.md`).
