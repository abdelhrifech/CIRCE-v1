## Slide 26
Dashboard – règles de gestion
Le dashboard est accessible par l’ensemble des coordinatrices et gestionnaires Pré-Prod ainsi que par l’ensemble des équipes de Nîmes et Wissous
Chaque utilisateur peut filtrer uniquement les données qui l’intéressent
On gérera des quantités attendues avec et sans entretien
Dans les quantités avec entretien, on calculera la valeur de l’entretien comme suit : 
Si la prépa n’est pas encore envoyée de Broadcast, alors le % d’entretien est de 8%
Si prépa envoyée, alors le % d’entretien est celui saisi dans Broadcast
Si on est sur une campagne contrôlée, alors % d’entretien est de 15%
On distinguera 3 types d’alertes concernant les manquants ou les surplus de réceptions :
Alerte sur les quantités reçues hors entretien : si quantité reçue < quantité sans entretien  alerte
Alerte sur la quantité reçue avec entretien : si (quantité reçue-quantité attendue avec entretien)/quantité attendue avec entretien) est supérieur à +/-10% alors  alerte
Alerte sur les réceptions faites alors que les IP ne sont pas saisies
Cas des réceptions sans IP
La Pré-Prod doit consulter ce dashboard pour connaître les cas de réception sans IP
Autant que possible, à la saisie des IP, elle gardera le nom renseigné par la plateforme qui l’a saisi en premier
Si elle doit corriger l’intitulé, elle doit en informer les plateformes pour qu’elles puissent ré-imprimer les feuilles de stock  une alerte peut suffire (vs mail) (voir si on peut automatiser cette alerte si on suit les màj de thème)
Le champs « dates de livraison prévisionnelle » doit pouvoir être renseigné manuellement par les gestionnaires pré-prod ainsi que des commentaires si besoin, afin de remplacer tous les échanges par mail sur les manquants jusqu’aux infos à J-3
