Circé aujourd'hui : du dossier vendu à l'atelier

Actions, statuts, catégorie et outil (Broadcast ou Circé), étape par étape. C'est l'existant, pas la cible. Sources : deck du kick-off (S…), deck Réception – Expédition du 14/10 (R…), référentiel des besoins et code de Circé lu en lecture seule.

Mise à jour du 02/11 : la cible de la validation admin devient l'option A (proposée par Circé à la réception, confirmée en lot par la Coordination, sans attendre la prépa ni l'Instruction OK ; 00_synthese_powerpoint.md §19.37). L'existant décrit ici est inchangé, avec un constat du code sur le fixe et le scro (voir l'étape 7).

À retenir

  1. L'état des réservations (EDR) décrit le dossier vendu ; ses données viennent de Broadcast. La liste des affiches décrit l'affiche reçue ; elle n'existe que dans Circé.
  2. Les deux avancent séparément : une affiche peut arriver avant ou après la préparation (S15).
  3. Instruction OK contrôle le dossier. Elle se fait après l'envoi de la préparation, et seulement pour le déroulant.
  4. La validation admin confirme le lien entre une affiche et ses dossiers, pour tous les formats. C'est elle qui met « affiche reçue » (anomalie ANO-05).

CircéAction Validation admin

Une case à cocher dans la fiche de l'affiche. Elle confirme : « cette affiche est bien celle de ces dossiers, pour ces quantités ».

Condition : la préparation est envoyée par Broadcast (S24) ; pour le déroulant, après Instruction OK (S15). Retour terrain du 02/11, expliqué par le code : au fixe, la prépa envoyée suffit ; au scro, l'Instruction OK est nécessaire, parce que la validation passe par la liaison des lignes de prépa du dossier (ReceptionListeAfficheController.cs:218-254), qui n'existent au scro qu'après l'Instruction OK.

Effets automatiques : le dossier apparaît dans le suivi de production de l'atelier (S28) ; l'EDR passe « Affiche reçue = Oui » (S32) ; déroulant : Trains › Préparation est alimenté (S49).

Points de vigilance (constatés dans le deck)

  • ANO-05 : « Affiche reçue = Oui » est mis par la validation admin, et non par la réception (S32, S49, S69). déduit Une affiche déjà en stock reste « non reçue » pour Broadcast tant que personne n'a coché.
  • PP-01 : le deck demande « Faut-il conserver la validation admin ? » (S75) et propose de la supprimer (S69).
  • INC-04 : l'ordre raccrochage, Instruction OK, validation admin change selon les slides (S15, S24, S25, S47, S49).
  • INC-05 : ce qui fait apparaître un dossier fixe dans l'atelier varie : le raccrochage (S24), la validation admin (S28) ou le bouton Colisage (S37).
  • ANO-14 : sans lien ni validation admin, la création des affiches « ne semble pas bloquée » (S29, à revoir).
  • INC-23 : depuis la matrice du 14/10 (R7), la validation admin du 8 m² scro à Wissous n'a plus d'acteur.

Ce que propose la maquette (pas encore validé)

  • Une seule validation Pré-Prod par dossier (« Validé Pré-Prod ») remplace Instruction OK et la validation admin. Décision du 27/10 : les deux verrous restent, indépendants. La validation admin est gardée, par affiche, faite par Circé au dernier des deux jalons (réception, préparation) quand tout concorde, sinon par la Coordination (remplacé le 02/11 par l'option A : proposée par Circé à la réception, confirmée en lot par la Coordination, sans attendre la prépa ni l'Instruction OK ; synthèse §19.37) ; l'Instruction OK suit la règle de Nariman (process par jalons, 2. PRE-PRODUCTION/process_preprod_avant_apres.html).
  • L'affiche est reliée au dossier dès la réception ; « affiche reçue » est mise par la réception (PP-02).
  • Onglet « Dossiers » (15/10) : dès la préparation reçue, Circé repère les visuels identiques ou proches sur plusieurs dossiers (par exemple « Promo » et « PROMOS »). Circé ne peut pas écrire dans Broadcast : la Pré-Prod demande la correction et rend la main, puis Broadcast renvoie la préparation corrigée (PP-08).
  • Thème changé dans Broadcast après Instruction OK et validation admin : Circé compare son thème à celui de Broadcast, dossier par dossier, et lève une alerte, critique si la production est lancée (PP-09). Aujourd'hui, rien ne les compare.
